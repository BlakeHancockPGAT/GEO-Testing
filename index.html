GEO A/B Test: llms.txt Optimization

This test isolates whether changes to llms.txt alone — with zero frontend code changes — can influence how AI tools respond to questions about PGA TOUR players.

Test Design

Both versions use the exact same player profile page. The only difference is the llms.txt file at the site root:

  • Version A: Current production llms.txt (season info, schedules, FAQs — no account mentions)
  • Version B: Same llms.txt + added sections for Free PGA TOUR Account and PGA TOUR App

The player profile page is IDENTICAL in both versions. The llms.txt is DIFFERENT.

Version A: Current llms.txt (Production)

Player page + the real production llms.txt from pgatour.com.

→ Player Profile (Version A) | → llms.txt (current)

Version B: Proposed llms.txt (With Account/App Sections)

Same player page + updated llms.txt with Free Account and App sections added.

→ Player Profile (Version B) | → llms.txt (proposed)

How to Test

  1. Open ChatGPT (logged in, with browsing enabled)
  2. Ask: "Look at this page and also check the llms.txt at the site root, then tell me what's going on with Tony Finau: [Version A URL]"
  3. Start a new chat, ask the same question with the Version B URL
  4. Compare: Does Version B's response suggest account creation or the PGA TOUR app?

What We're Measuring

  • Does the AI mention creating a free PGA TOUR account?
  • Does the AI suggest following the player for scoring alerts?
  • Does the AI mention the PGA TOUR app?
  • Does the AI link to pgatour.com/register?
